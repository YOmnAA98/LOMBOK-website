# 📘 Case Study: LOMBOK – Plants Website

LOMBOK is a plant-focused website interface designed to present plant information and related content through a clean and structured user interface.

The project focuses on building a visually organized layout using HTML, CSS, and Bootstrap while maintaining clarity, consistency, and simple navigation.

---

## 🔗 Live Demo

[LOMBOK Link](https://lombok-website.vercel.app/)

---

## 📌 Project Overview

The goal of this project was to create a content-driven website that highlights plant information using a clear visual structure and organized page layout.

Core focus:

- Clean section-based layout
- Readable content presentation
- Consistent spacing and typography
- Simple user flow between pages
- Structured layout using Bootstrap grid system

This project demonstrates frontend layout fundamentals and UI composition using static technologies.

---

## ✨ Key Features

- Hero section with visual emphasis
- Content sections for plant information
- Login and registration pages
- Grid-based layout using Bootstrap
- Consistent visual hierarchy
- Lightweight and simple navigation

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- Bootstrap

---

## 🧩 Development Approach

The project focuses on core UI principles:

- Semantic HTML structure
- Organized layout using Bootstrap grid
- Separation between structure and styling
- Consistent spacing and alignment
- Clear visual hierarchy for content readability

The implementation prioritizes simplicity and maintainability while demonstrating frontend layout fundamentals.
